# 📝 To-Do List Application

A graphical To-Do List Application developed using Python and Tkinter as part of my Python Development Internship – Month 1.

## ✨ Features

- Add tasks
- View tasks
- Mark tasks as completed
- Remove tasks
- Clear completed tasks
- Progress bar
- Completion percentage
- Task counter
- Input validation
- Exit confirmation
- Scrollable interface

## 🛠️ Technologies Used

- Python
- Tkinter
- ttk
- Object-Oriented Programming

## 📚 Concepts Used

- Classes and Objects
- Functions
- Lists
- Dictionaries
- Conditional Statements
- Event Handling
- GUI Development
- Progress Tracking
